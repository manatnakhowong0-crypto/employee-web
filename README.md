## 🧾 ออกสลิปเงินเดือน (Payslip → PDF)

หน้า **จัดการ → ออกสลิปเงินเดือน** สร้างสลิปเงินเดือนเป็นไฟล์ PDF:

- กรอกข้อมูลพนักงาน + รายได้ (เรท × จำนวนวัน) + รายการหัก แล้วดูตัวอย่างใบสลิปสด ๆ ด้านขวา
- ปุ่ม **⚡ ดึงวันทำงาน + ยอดเบิกของเดือนนี้** — เลือกพนักงาน + เดือน/ปี ระบบจะนับวันมาทำงานจากชีต1 ให้อัตโนมัติ (เต็มวัน = 1, ครึ่งวัน/มาหลัง 11:00 = 0.5) และดึงยอดเบิกเงินล่วงหน้าของเดือนนั้นมาใส่ช่อง "Salary advance" ให้เลย
- หักประกันสังคม 5% (สูงสุด 750 บาท) และภาษี ณ ที่จ่าย แบบติ๊กเลือกได้ — เพื่อให้สอดคล้องตามกฎหมาย
- **⬇️ ดาวน์โหลด PDF** ได้ไฟล์ทันที หรือ **🖨️ พิมพ์** แล้วเลือกปลายทาง "บันทึกเป็น PDF" (คมชัดกว่า)
- มีช่องเซ็น "ผู้จ่ายเงิน / ผู้รับเงิน" และอ้างอิง พ.ร.บ. คุ้มครองแรงงาน ม.57 ท้ายใบ

> โลโก้ร้านฝังอยู่ในไฟล์ `js/logo.js` (แก้รูปได้โดยแทนที่ไฟล์นี้) — ที่อยู่ร้านแก้ได้ในตัวแปร `COMPANY` ที่หัวสคริปต์ของ `pages/payroll.html`

## 📊 ตาราง Attendance Grid (หน้าหลัก)

- เลือก **พนักงาน / ปี / เดือน** ได้อิสระ
- สีตามเวลาเข้างาน: 🟢 ปกติ (ก่อน 09:30) · 🟡 สาย (09:31–11:00) · 🟠 ครึ่งวัน (หลัง 11:00) · 🔴 ขาด · ⬜ เสาร์–อาทิตย์
- การ์ดสรุปยอดรวมทั้งเดือน
- **เมื่อล็อกอินแล้ว** คลิกที่ช่องเพื่อ **แก้ไข / เพิ่มย้อนหลัง / ลบ** เวลาเข้างานได้ — บันทึกลงชีต "ชีต1" ถาวร

## ✏️ การแก้ไขเวลาแบบถาวร (สำคัญ)

การแก้ไขบนหน้าเว็บจะเขียนลง **"ชีต1"** โดยตรง (ไม่ใช่เก็บแค่ในเครื่อง):

- **แก้เวลา** วันที่มีข้อมูลอยู่แล้ว → อัปเดตคอลัมน์ "เวลาเริ่มต้น" ของแถวนั้น
- **เพิ่มย้อนหลัง** (มาทำงานแต่ไม่ได้เช็คชื่อ) → เพิ่มแถวใหม่ในชีต1
- **ลบ** → ลบแถวของวันนั้นออกจากชีต1

> ⚠️ ต้องนำ `Code.gs` เวอร์ชันใหม่ไปวางใน Apps Script แล้ว **Deploy ใหม่** ฟีเจอร์นี้จึงทำงาน (ดูหัวข้อถัดไป)

## 🔧 ตั้งค่า Google Apps Script

1. เปิด Google Sheet → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิม แล้ววางเนื้อหาจากไฟล์ `Code.gs` ใหม่ทั้งหมด → บันทึก
3. กด **Deploy → New deployment** (หรือ Manage deployments → แก้ไขอันเดิม) แบบ Web app
   - Execute as: **Me**
   - Who has access: **Anyone**
4. คัดลอก URL ที่ได้ มาวางใน `js/config.js` ที่ `API_URL`
   (ถ้าใช้ URL เดิมและแก้แบบ "Manage deployments" ไม่ต้องเปลี่ยน URL)

```js
const CONFIG = {
  API_URL: "https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec",
  ...
};
```

## 🆕 อัปเกรด: รหัสผ่าน + LINE Notify + วันหยุด + ฝ่ายโอนเงิน

### ⚙️ ตั้งค่าใน Code.gs (ด้านบนสุดของไฟล์)
```js
var EMP_PASSWORD   = "sanae123";   // รหัสพนักงาน (ส่งใบลา/เบิกเงิน/สลับวันหยุด)
var ADMIN_PASSWORD = "admin999";   // รหัสแอดมิน (เปิดหน้าฝ่ายโอนเงิน)
var LINE_TOKEN     = "";           // ใส่ LINE Notify Token เพื่อเปิดแจ้งเตือน
```

### 📋 ต้องสร้าง 2 ชีตใหม่ (หัวตารางตรงตามนี้)
1. **จัดสรรวันหยุดพนักงาน** — คอลัมน์: `รหัสพนักงาน | ชื่อ-นามสกุล | วันที่หยุด | ประเภทวันหยุด | หมายเหตุ`
   - `วันที่หยุด` ใส่รูปแบบ `YYYY-MM-DD` (เช่น 2026-07-05)
2. **สรุปเงินเดือน** — คอลัมน์: `ชื่อ-นามสกุล | เงินเดือน | รวมวันทำงาน | ค่าเบี้ยเลี้ยง | โบนัส | ล่วงเวลา | หักอื่นๆ | รวมเงินได้ | ธนาคาร | เลขบัญชี`

### 🔓 พฤติกรรมหน้าเว็บ
- **แจ้งลา & ปฏิทิน** + **เบิกเงินล่วงหน้า**: เปิดดูได้เลย (สาธารณะ) แต่ต้องกรอก **รหัสพนักงาน** ตอนกดส่ง
- **ปฏิทิน**: เลือกชื่อตัวเองจาก dropdown → เห็นวันหยุด (เขียว) / วันลา (แดง) → คลิกวันหยุดเพื่อสลับวัน (ต้องใส่รหัสพนักงาน)
- **ฝ่ายโอนเงิน** (🏦): เปิดมาเจอหน้าล็อก ต้องกรอก **รหัสแอดมิน** ก่อนถึงจะเห็นข้อมูล + มีรายการบัญชีให้กดคัดลอก
- **LINE Notify**: แจ้งเตือนเมื่อมีใบลา / เบิกเงิน / สลับวันหยุด (ถ้าใส่ LINE_TOKEN)

วาง Code.gs → Deploy → Manage deployments → แก้ deployment เดิม → **New version** → Deploy (สิทธิ์ "Anyone")

## 🔒 อัปเดตความปลอดภัย (Security Hardening)

**สำคัญ:** เพิ่มการตรวจรหัสผ่านฝั่งเซิร์ฟเวอร์ให้ทุกคำสั่งที่เขียน/ลบข้อมูล — กันการยิง POST ตรงเข้า `/exec`

- คำสั่ง `writeAttendance`, `updateAdvance`, `deleteAdvance`, `savePayslip` ต้องแนบรหัสระบบจัดการ และเซิร์ฟเวอร์ `_verify` ก่อนทำงานเสมอ
- ย้ายการตรวจ **รหัสเข้าระบบไปฝั่งเซิร์ฟเวอร์** (`LOGIN_PASSWORD` ใน Code.gs) — ไม่เก็บรหัสไว้ใน `config.js` อีกต่อไป
- กัน **Formula/CSV Injection**: ค่าที่ผู้ใช้กรอกซึ่งขึ้นต้นด้วย `= + - @` จะถูกใส่ `'` นำหน้าก่อนบันทึกลงชีต
- แก้ **วันลา off-by-one**: ชีตเก็บวันสิ้นสุดจริง ปฏิทินค่อยบวก 1 วันตอนแสดง

### ⚙️ ตั้งค่ารหัสใน Code.gs (บนสุด)

var LOGIN_PASSWORD = "sanaethai15";   // รหัสเข้าระบบจัดการ (แก้เวลา/โอน/ลบ/บันทึกสลิป)
